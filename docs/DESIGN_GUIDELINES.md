# PEI COMPROMISO 360° — DESIGN GUIDELINES

## Objetivo

Diseñar una plataforma institucional de alta calidad visual, con identidad propia, que no parezca una plantilla generada por inteligencia artificial.

## Referencias obligatorias

1. Utilizar la skill `frontend-design` instalada en `.agents/skills/frontend-design/SKILL.md`.
2. Respetar `AGENTS.md` y `PROJECT_MEMORY.md`.
3. Utilizar la maqueta visual aprobada del proyecto como referencia principal.
4. Preservar los componentes y funcionalidades existentes.

## Dirección artística

Estilo: institucional contemporáneo, ceremonial, elegante y sobrio.

La plataforma representa el compromiso de los trabajadores de tres campus con el Plan Estratégico Institucional.

No es una landing comercial, una aplicación financiera ni un dashboard SaaS genérico.

## Sistema visual

Colores provisionales:
- Azul profundo: #09264A
- Azul institucional: #124B87
- Azul interactivo: #1769B3
- Dorado ceremonial: #D6AD60
- Fondo: #F6F8FC
- Texto: #172B45
- Blanco: #FFFFFF

Usar tokens CSS. No introducir colores arbitrarios.

Tipografía:
- Elegir una familia profesional con personalidad y excelente legibilidad.
- Mantener una escala tipográfica consistente.
- No utilizar tipografías decorativas innecesarias.
- Priorizar legibilidad a distancia en el mural.

## Reglas anti-diseño genérico

1. No generar layouts idénticos para todas las páginas.
2. No colocar tarjetas KPI indiscriminadamente.
3. No utilizar gradientes sin justificación.
4. No utilizar emojis.
5. No añadir sombras exageradas.
6. No abusar de bordes redondeados.
7. No utilizar glassmorphism por defecto.
8. No generar contenido ficticio presentado como real.
9. No inventar logotipos, fotografías ni edificios institucionales.
10. No añadir elementos decorativos sin función visual.
11. No utilizar animaciones repetitivas sin propósito.
12. No alterar el diseño aprobado para experimentar con tendencias.

## Experiencia móvil

El registro debe sentirse rápido y natural.

- Una acción principal por pantalla.
- Campos grandes y accesibles.
- Etiquetas visibles.
- Validaciones comprensibles.
- Botones táctiles cómodos.
- Confirmación inmediata.
- Sin pasos innecesarios.

## Mural ceremonial

Es la pieza visual principal.

Debe tener:
- Contador central protagonista.
- Jerarquía visual excepcional.
- Identidad institucional.
- Participación diferenciada por campus.
- Tarjetas de participantes legibles.
- Animaciones suaves.
- Mosaico PEI.
- Composición optimizada para 1920 × 1080.

No convertirlo en un dashboard convencional.

## Panel administrativo

Debe priorizar:
- Claridad.
- Orden.
- Legibilidad.
- Comparación de datos.
- Jerarquía.
- Consistencia.
- Tablas y gráficos útiles.

No utilizar decoración ceremonial excesiva en administración.

## Protocolo de cambios

Cuando el usuario solicite modificar una pantalla:

1. Identificar el componente responsable.
2. Consultar las reglas visuales pertinentes.
3. Modificar únicamente los archivos necesarios.
4. Conservar las decisiones aprobadas.
5. No explorar alternativas sin solicitud explícita.
6. Verificar responsive y compilación.
7. Responder con un resumen breve.

## Control de calidad visual

Antes de dar por terminado un componente, verificar:

- ¿Se parece a la referencia aprobada?
- ¿Tiene una jerarquía clara?
- ¿Hay elementos innecesarios?
- ¿Los números están alineados?
- ¿La tipografía es consistente?
- ¿Funciona en móvil?
- ¿Parece una interfaz institucional real?
- ¿Se ha conservado la funcionalidad existente?

Si alguna respuesta es negativa, corregir el problema concreto antes de finalizar.

## Regla final

La creatividad debe utilizarse para mejorar la ejecución del diseño aprobado, no para reemplazarlo.

Priorizar precisión visual, coherencia, accesibilidad, rendimiento y mantenibilidad.
